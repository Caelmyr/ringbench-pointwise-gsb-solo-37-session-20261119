# RingBench 面探测器图像工作台

RingBench 用于本地查看和分析平面衍射探测器的单通道计数图。工作台保留计数矩阵、环心、排除像素和主要分析设置。合成演示可直接运行，展示不同探测器覆盖、衍射环、肩形峰和成组斑点。

## 启动

```sh
docker compose up -d --build --wait
```

默认访问 <http://127.0.0.1:18940/>。停止时执行 `docker compose down`。工程保存在独立的 `ringbench-data` 数据卷。可以用 `RINGBENCH_PORT` 修改本机端口，用 `RINGBENCH_SUBNET` 修改容器网络网段。建议只在本机运行。

也可在 Python 3.11 或 3.12 的虚拟环境安装 `requirements.txt`，执行 `python -B app.py`。直接启动默认保存在 `data/`。使用 `RINGBENCH_DATA_DIR` 指定数据位置。使用 `PORT` 指定监听端口。

## 原图到结果

1. 导入灰度 PNG、单帧灰度 TIFF 或二维数值 NPY，或载入「铜合金粉末 · 合成」「压延晶粒 · 合成」「偏心探测器 · 合成」。同一工程可保存同尺寸的多张曝光。
2. 在「探测器」点击像素读取计数、原图坐标与遮罩状态。调整显示窗口、色表或拉伸。可圈矩形坏区、添加计数遮罩或导入同尺寸 NPY 遮罩。导出排除像素为布尔矩阵，其中真值表示排除。
3. 设置环心、像素尺寸、距离和波长。沿一条参考环布标点可预览圆拟合，确认后应用。已有测量半径和参考晶面间距时，可从一条或多条环估计距离并查看残差。
4. 「径向积分」对同一图的像素分箱，计算均值、计数和支撑，标出局部径向峰。「角向曲线」在所选环带和方位内分箱。「极坐标图」显示平均计数或有效像素比例，可点击分箱读取值。径向单位可选像素、毫米、2θ 或 q。
5. 「横截面」沿线或窄带取样，可用原图选择端点。「斑点测量」提供标点和候选搜索，报告局部背景与净计数。「曝光差图」对同位置的主曝光、参照曝光做手动或拟合归一后比较。
6. 「更多分析」包括计数直方图、行列条带检查、重复曝光统计、暗场和平场校正、几何响应校正、径向谱比较、角向谐波、参考环跟踪、单峰区积分面积、等强线、散射向量和整环覆盖。校正图可下载为 NPY 后作为新计数图导入。
7. 「保存工程 ZIP」保存可重新打开的工程设置、计数矩阵和导入遮罩。「导出分析」生成当前保存版本的结果 ZIP，含图、数值表、来源哈希和分析设置。部分检查页面的临时参数随页面会话保留，重新打开工程时使用它们的默认值。

## 坐标、数据与范围

- 探测器坐标从 0 开始，整数表示像素中心。X 向右，Y 向下。方位由向右方向在图像上顺时针增加，再减去已设置的角度零位。跨零度扇区使用起始方位及跨度。
- 数据统一存为小端 float32，非有限值记作缺失。PNG 或 TIFF 原始像素未做色彩变换。上传的整数超过 float32 精确整数范围时会按 float32 舍入。原始文件名、采集类型、输入数值类型及规范化矩阵的 SHA-256 随工程保存。
- 主要积分将像素中心分到箱中，CSV 空值表示箱无有效计数。环带覆盖用等面积的极坐标采样估计整环几何支持，支持分母包含探测器外。线剖面可保留部分双线性支撑，不把遮罩像素补为零。
- 平面几何假定正对入射束，未补偿探测器倾斜或畸变。环心用点集圆拟合。径向峰表以局部极大和半突出度宽报告测量。量纲与示意算法适合做本地分析和教学。标注「合成」的素材由程序生成，未使用实际实验或材料认证数据。
- 摄取限制为每边 16 至 4096 像素且总像素不超过 4,194,304。单工程最多 8 帧，工作区最多 64 个工程或约 2 GiB 数值存储。极坐标像素支撑、显示限值和轮廓预算按实际算法计算，放大显示不增加探测器分辨率。
- 项目使用 SQLite 在容器独立卷内保存，保存冲突会要求刷新。下载 NPY、CSV、PNG 不写回原始矩阵。

后台行数可由 `python3 scripts/count_backend.py --project-root . --source-root .` 复算。

坐标与常规面探测器分析术语参见 [pyFAI 的积分说明](https://www.silx.org/doc/pyFAI/dev/pyFAI.html)及 [GSAS-II 的面探测器说明](https://advancedphotonsource.github.io/GSAS-II-tutorials/help/image.html)。
